Colas - Queues

Significado de cada puntero, color y recuadro en los dibujos
frente (*)

Puntero que no puedo perder: apunta siempre al primer nodo que ingresó y es por donde salen los datos en unqueue().

fin (**)

Puntero de ingreso: apunta siempre al último nodo de la cola. A través de fin->sgte enganchamos los nuevos nodos en queue().

int retorno

Variable de rescate: guarda frente->info antes de borrar el nodo. Podés enviarla a una cola auxiliar para conservar el dato.

aux ───►

Puntero auxiliar celeste: guarda la dirección del nodo frente (aux = frente) para poder liberar la memoria con delete aux;.

nodo a borrar

Recuadro rojo: señala el nodo que quedó desvinculado del frente y cuya memoria está a punto de ser eliminada del Heap.

Resumen del Apunte: 07 - Colas - Queues

queue / enqueue / encolar / insertarCola

  1. Crear el nodo y asignar el dato:
    Nodo *nuevo = new Nodo();
    nuevo->info = dato;
  2. Asignar el *sgte de nuevo a NULL:
    nuevo->sgte = NULL;
  3. Verificar los casos posibles:
    a) Cola vacía: if(frente == NULL) frente = nuevo;
    b) Hay nodos: else fin->sgte = nuevo;
  4. Mover fin a su lugar:
    fin = nuevo;

unqueue / dequeue / desencolar / quitarCola

  1. Guardar la información del nodo que voy a sacar:
    int retorno = frente->info;
  2. Crear puntero auxiliar con la dirección a borrar:
    Nodo *aux = frente;
  3. Para borrar, tengo dos casos posibles:
    a) Solo queda 1 nodo (frente == fin):
    frente = NULL; fin = NULL;
    b) Quedan 2 o más nodos:
    frente = aux->sgte;
  4. Borrar *aux: delete aux; y retornar retorno.
struct Nodo{
    int info;
    Nodo *sgte;
};

void queue(Nodo *&frente, Nodo *&fin, int dato){
    Nodo *nuevo = new Nodo();
    nuevo->info = dato;
    nuevo->sgte = NULL;
    if(frente == NULL){
        frente = nuevo;
    }else{
        fin->sgte = nuevo;
    }
    fin = nuevo;
}

int unqueue(Nodo *&frente, Nodo *&fin){
    int retorno = frente->info;
    Nodo *aux = frente;
    if(frente == fin){
        frente = NULL;
        fin = NULL;
    }else{
        frente = aux->sgte;
    }
    delete aux;
    return retorno;
}
