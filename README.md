## 📚 Laboratorio de Colas (Queues)

Explora de manera interactiva el comportamiento de las Colas (estructura **FIFO**: First In, First Out) y domina sus algoritmos en C++.

### ✨ ¿Qué incluye?

* **Pizarra Interactiva:** Simula visualmente las operaciones `queue()` (encolar) y `unqueue()` (desencolar).
* **Guía Visual de Punteros:** Aprende el rol exacto de `frente`, `fin`, la variable de rescate `retorno` y el puntero temporal `aux`.
* **Modo Presentación (Clase):** Navega paso a paso por el código para ver qué línea se ejecuta y cómo afecta a la estructura de la memoria.
* **Manejo de Memoria:** Observa cómo se asigna memoria en el Heap y cómo se libera el "nodo a borrar" de forma segura.
* **Código en Vivo:** Copia el `main()` generado automáticamente con todas las declaraciones y movimientos que hayas hecho en la pizarra.
